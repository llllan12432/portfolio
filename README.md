# Project portfolio

Recruitment portfolio for AI application and software development internships.

Live entry: https://llllan12432.github.io/portfolio/

The static site in `docs/` contains a synthetic memory-ranking explorer, original Java-game footage, source archives and verification notes. There are no API keys, personal conversations, remote model calls or database connections. Source archives are downloadable without a GitHub account.

The memory explorer computes the original weighted ranking policy over clearly marked synthetic similarity inputs. It is not a live semantic-search or LLM demonstration. The game clip predates the October portfolio maintenance. Original assessment and later maintenance are distinguished on the page.

For local preview, run `python3 -m http.server 8768 --bind 127.0.0.1 --directory docs` and visit http://127.0.0.1:8768.

Deployment: GitHub Pages, branch `main`, folder `/docs`. `.nojekyll` keeps these buildless assets unchanged.
